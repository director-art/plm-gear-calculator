# Калькулятор редуктора ПЛМ

Адаптивное веб-приложение для сравнения конфигурации подвесного лодочного мотора до и после изменений. Можно отдельно менять редуктор, винт либо редуктор и винт одновременно. Передаточное число рассчитывается по количеству зубьев или вводится вручную. Калькулятор показывает обороты двигателя и гребного вала, теоретическую и расчётную скорость, исходное проскальзывание, изменение шага, передаточного числа и теоретического крутящего момента.

## Запуск

```bash
npm start
```

Откройте <http://localhost:8000>.

## Проверка расчётов

```bash
npm test
```
