# Калькулятор редуктора ПЛМ

Адаптивное веб-приложение для расчёта характеристик подвесного лодочного мотора при замене шестерён редуктора. Передаточное число можно автоматически вычислять по количеству зубьев или вводить вручную. Калькулятор сравнивает обороты гребного вала и теоретический крутящий момент, рассчитывает теоретическую скорость и проскальзывание, прогнозирует скорость после замены и требуемый шаг винта.

## Запуск

```bash
npm start
```

Откройте <http://localhost:8000>.

## Проверка расчётов

```bash
npm test
```
